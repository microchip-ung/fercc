I want you to build a rust implementation of the mup1cc CLI tool.

The script has a lot of dependencies most of which I want you to build yourself:
- a YANG parser (build your own)
- a JSON parser (use a dependency)
- a YAML parser (use a dependency)
- a http(s) client (use a dependency)
- support/yang-enc/yang-utils.rb (port to rust)
- support/yang-enc/yang-enc.rb (port to rust)
- support/yang-enc/yang-schema.rb (avoid this, rust is fast enough to parse and build the schema from scratch on every invocation)
- a CBOR encoder / decoder (im open to a dependency for this if you can suggest a mature one, otherwise build yor own)
- a MUP1 client (build your own / port mup1cc's ruby implementation to rust. Can also look at ~/sw-velocitydrive-devclient)
- a CoAP client (build your own / port mup1cc's ruby implementation to rust. Can also look at ~/sw-velocitydrive-devclient)

I want you to clone the command line interface of mup1cc.
The implementation and all dependencies should use a stable conservative version of rust.

To verify your implementation look at the test cases in ~/sw-velocitydrive-devclient and ~/sw-lmstax-labs/support/yang-enc/spec and port them to Rust.
There is also a board that you can test your implementation against at /dev/ttyACM0. This is the ultimate test: whether the tool acts as drop-in replacement for mup1cc.
